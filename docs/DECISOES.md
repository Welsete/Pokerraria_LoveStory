# Decisões de design · Pokerraria: LoveStory

Registro das decisões do Welsete. O grill-me do mod adiciona entradas aqui. Formato: data, decisão, motivo (se
houver). Perguntas ainda sem resposta ficam no fim.

## Decididas

- 2026-11-03 · A Misty fica parada no seu ponto do Ginásio. A caminhada fica guardada para depois.
- 2026-11-03 · As spritesheets de VFX são geradas no Gemini pelo Welsete a partir de `art/vfx/prompts/`; o
  Claude recorta e anima.
- 2026-11-03 · Toda mudança vai direto para a pasta Mods do PC do Welsete para ele testar antes do push.

- 2026-11-03 · Golpes básicos são desenhados por código; os avançados vão para o gerador de imagem. Economiza os dois. Critério e listas em `VFX.md`.
